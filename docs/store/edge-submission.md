## 4. 步骤 6：隐私（Privacy）

### 4.1 单一用途说明

```
本扩展为哔哩哔哩（bilibili）网站的视频页与直播页提供两项增强：一是音量增益，让用户可以把播放音量提升到网站原生上限（100%）之上，并按 UP 主分别记忆；二是在直播沉浸全屏时，把当前直播间悬挂中的醒目留言（Super Chat）显示在播放器画面角落，因为沉浸全屏下网站原生的留言侧栏不可见。
```

### 4.2 权限理由（逐个权限）

**`storage`**

```
用于在本地保存用户的音量增益设置：插件总开关，以及按 UP 主分别记录的音量增益值（视频页按 UP 主 mid、直播页按主播 uid 分桶），以便用户再次观看同一 UP 主的视频或直播时自动套用上次的增益。另保存醒目留言浮层的开关与显示位置。全部数据仅存于用户本地浏览器的 chrome.storage.local，不上传、不共享，用户可在扩展面板中一键清空。
```

**`activeTab`**

```
用于扩展的 popup 面板在用户点击扩展图标时读取当前标签页的地址，以判断当前是哔哩哔哩视频页还是直播页，从而显示对应的状态信息（当前页面类型、识别到的主播、当前增益值）与可用设置项。扩展不读取页面正文内容，不使用该权限做任何其他用途。
```

**`https://api.live.bilibili.com/*`**

```
直播页需要读取哔哩哔哩官方的醒目留言列表接口（GET /av/v1/SuperChat/getMessageList?room_id=<直播间号>），以获取当前直播间正处于悬挂展示中的醒目留言内容，进而显示在沉浸全屏下的播放器角落。该请求由用户当前打开的哔哩哔哩直播间页面发出，每隔 10 秒一次，只读取该直播间公开可见的留言内容；扩展不向该接口发送任何用户数据，不收集、不存储接口返回内容以外的信息，也不与任何其他服务器通信。该权限是本扩展除本地存储外唯一的网络访问。
```

### 5.1 详细说明

```
【它解决什么问题】

哔哩哔哩的音量滑块最高只有 100%。当源视频或直播本身录制音量偏小、设备音量已开满时，你就没有别的办法了。本扩展在网站原生音量之上叠加一条独立的「增益」轨道，把可调范围扩展到最高 500%（约 14.62 倍幅值、+23.3dB），并且按 UP 主分别记忆——下次进同一个主播的页面会自动套用你上次设定的增益。

另一件事：在直播间进入沉浸全屏后，网站右侧的醒目留言（Super Chat）侧栏会被隐藏，此时你看不到任何留言。本扩展会在全屏画面的角落把当前悬挂中的醒目留言显示出来，包含头像、用户名、金额和留言正文。

【音量增益】

· 范围 50%–500%，默认 100%（不改动时与你原本听到的完全一致）
· 采用感知等量刻度：滑块每一档的听感变化都相同，越往上不会觉得「越调越不明显」
· 分层设计，不修改网站原生音量滑块，最终响度 = 原生音量 × 增益
· 内置压缩限幅，极限增益下也不会出现削波爆音
· 按 UP 主记忆：视频页与直播页分别记录，各自独立
· 滑块就在原生音量按钮旁边，鼠标悬停展开，支持拖动与滚轮微调

【直播全屏醒目留言】

· 仅在「沉浸全屏」下显示，避免与页面原有的留言栏重复
· 可设置显示在画面四角之一（默认右上）
· 卡片配色取自留言数据本身，与网站原生配色一致
· 同时悬挂多条时按金额从高到低排列，最多显示 3 条，更多则折叠为「+N 条」
· 可逐条手动关闭

【快捷键】

· Alt + ↑ / ↓ —— 增益 ±10%
· Alt + 0–9 —— 快速定档
· Alt + M —— 静音切换
· 光标位于输入框内时快捷键自动放行，不会影响你打字

【隐私】

不收集、不上传任何个人信息，无统计、无广告、无远程代码。所有设置只保存在你自己的浏览器本地，卸载即清除。

【说明】

本扩展为第三方个人开源项目，与哔哩哔哩官方无任何关联。源码与反馈：https://github.com/YuMo-233/bilibili-volume-boost
```

## 6. 步骤 8：认证测试说明

```
本扩展无需登录即可测试全部功能，也不依赖任何测试账号。

【测试音量增益】
1. 打开任意 B 站视频页，例如 https://www.bilibili.com/video/BV1Qhe26TEK9/
2. 在页面任意空白处点击一次（用于激活音频上下文），随后确认视频开始播放
3. 播放器底部控制栏上会出现一个「喇叭」图标（位于原生音量按钮右侧），鼠标悬停该图标会向上展开一个竖直滑块
4. 拖动滑块，或在滑块上滚动滚轮，即可改变增益；按 Alt + ↑ / Alt + ↓ 也可调整，页面底部会显示当前增益百分比
5. 按 Alt + M 可切换静音

【测试直播全屏醒目留言】
1. 打开任意正在直播的直播间，例如 https://live.bilibili.com/3947892
2. 点击播放器右下角的全屏按钮，进入沉浸全屏（Fullscreen API 全屏）
3. 如果该直播间当前有正在悬挂的醒目留言，画面右上角会出现留言卡片（含头像、用户名、金额、留言正文，底部有剩余时间进度条）
4. 请注意两个前提：卡片仅在「沉浸全屏」下显示（网页全屏不显示）；且该直播间当前必须确实有醒目留言在悬挂，否则不会出现
5. 若测试时看不到卡片，可先访问下面这个公开接口确认该直播间当前是否有留言，把 room_id 换成直播间号：
   https://api.live.bilibili.com/av/v1/SuperChat/getMessageList?room_id=3947892
   返回的 data.list 非空即表示当前有留言在悬挂，此时进入全屏应当能看到卡片

【网络行为说明】
本扩展全部网络请求只有一条：每隔 10 秒 GET 上述醒目留言列表接口，无需登录态。除此之外不产生任何网络请求，不加载远程代码。

【隐私】
不收集、不上传任何用户数据；所有设置保存在浏览器本地。
```
