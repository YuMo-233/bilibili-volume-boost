# 0005-全屏醒目留言浮层：自绘复刻而非搬运原生

**状态**: accepted

**决策**: 直播间沉浸全屏下的醒目留言（SC）显示，采用**拦截页面 WebSocket 取数 + Shadow DOM 自绘卡片**，注入点为播放器列内的 `.live-player-mounter`（全屏随行，右上角定位）。**不搬运** B 站原生 `pay-note` 面板 DOM 节点。

**痛点根因（实测）**: 原生 SC 面板 `#pay-note-panel-vm` / `.pay-note-setting` 位于右侧栏 `.aside-area`（内含 `.chat-overlay-layer`），与播放器列 `.player-ctnr` 是**兄弟节点**；全屏时 B 站给 `<body>` 加 `hide-aside-area`，且沉浸全屏（Fullscreen API）本身只渲染全屏元素子树。实测 `document.querySelector('.player-ctnr').querySelectorAll('[class*=pay-note]').length === 0`——SC 完全不在播放器内，全屏必然看不见。

**原生卡片结构（实测）**:
```
.pay-note-setting > .pay-note-panel > .card-list > .card-wrapper
  └ .card-item-box.child > .card-item
      ├ .totle        ← 背景色块（实测 rgb(229,77,77)）
      ├ .progress     ← 悬挂倒计时进度条
      ├ .face-img     ← 头像
      └ .price > .currency-icon（base64 电池图标） + .price-tag
```
默认**只显示头像 + 价格 + 进度条**，留言内容需点击卡片弹出详情才可见。

**理由**:
- SC 的核心价值是留言内容，而原生卡片默认不显示留言。搬运原生面板进播放器，全屏下只能看到一张张"价格牌"，需逐张点击才读到内容。
- `SUPER_CHAT_MESSAGE` 载荷自带 `background_color` / `background_bottom_color` / `background_price_color` / `font_color` 等字段，自绘直接取用服务端下发色值，**颜色与原生一致且无需硬编码价格色阶**。
- 多卡叠放、价格排序、上限折叠、手动关闭等交互由插件完全可控；搬运方案下这些全部由 B 站控制，插不上手。
- 搬运方案依赖 `pay-note-*` / `card-item-*` class，B 站改版即失效；自绘仅依赖协议 CMD（相对稳定）。

**被否决方案**:
- **搬运原生面板**:已实测可行（移入 `.web-player-inject-wrap` 后稳定渲染，Vue 6 秒内未回收节点，可正常还原），但存在"留言不常显 + class 易变 + 样式需覆写 + 多卡排序不可控"四项代价。
- **HTTP 轮询** `getMessageList`:只能拿当前悬挂项，非实时且会丢消息（仅保留作初始回填）。
- **DOM 监听原生卡片**:无结构化字段（无 uid / 价格数值 / end_time），且 class 易变。

**已知取舍**:
- 注入点选择播放器列内的 `.live-player-mounter`（与 `<video>`、`.web-player-inject-wrap` 同级），保证沉浸全屏与网页全屏下都在全屏元素/播放器内。
- 卡片视觉为"高保真复刻"而非"字节级一致"：以服务端色值 + 头像 + 用户名 + 价格 + 留言五要素还原，电池图标等 B 站私有资源不自带。

**落地细节（已定）**:
- 数据源：拦截页面 WebSocket，监听 `SUPER_CHAT_MESSAGE`（含 `_JPN` 变体）与 `SUPER_CHAT_MESSAGE_DELETE`。
- 显示时机：仅沉浸全屏（网页全屏/普通状态不显示，避免与原生公屏 SC 重复）。
- 初始回填：进入全屏时调用一次 HTTP 接口拉取"当前悬挂中"的 SC，随后切换到 WebSocket 增量。
- 生命周期：显示至该条 `end_time`，支持手动关闭；收到 DELETE 即时移除对应卡片。
- 叠放：按价格降序纵向排列，最多 3 条，超出折叠为 "+N 条"。
- 过滤：默认全部显示，不设价格阈值。
- 开关：popup 独立开关（与音量总开关分离），默认开启。
- 显示位置：popup 提供左上 / 右上 / 右下 / 左下四角可选，默认右上；仅作用于 SC 浮层，音量滑块仍跟随原生控制栏。
