# 0014-视频页控制栏按钮纵向对齐（复刻原生确定高度）

**状态**: accepted

**症状（实测，2026-10）**: 视频页（bpx 播放器）增益按钮与原生音量键**不在同一水平线**：插件按钮偏下数像素、图标偏小，截图对比中两个喇叭明显矮一截、下沉。

**根因（真实页面取证）**:
- `.bpx-player-control-bottom-right` 行高实测 35px；原生按钮为**确定高度 22px**——flex 拉伸规则下「确定高度 + stretch」等价 flex-start，故原生按钮贴行顶排布（两者同 y=523）；
- 插件宿主默认 `height:auto`，被同一 flex 行拉伸到整行高（实测 24×**35**），内部 22px 按钮盒按 `align-items:center` 居中 → 整体下沉约 6.5px；
- 图标尺寸：原生音量图标 svg 36×22、viewBox 88×88、meet 缩放 0.25，实际字形约 16×14.6px；插件图标 17px svg 的实际字形约 13×10px，明显偏小。
- 直播页（新版播放器）此前无此问题：原生按钮 30px 且在行内居中，宿主 auto 高度恰好同样居中，故只在视频页可见。

**决策**:
1. 宿主高度复刻锚点（`getComputedStyle(anchor).height`，bpx 实测 22px）→ 与原生按钮走同一排布规则（同顶对齐/同类居中）；确定高度使宿主对容器对齐方式的变化自适应，不会重新失配。**仅视频页启用**：直播页原生为居中排布且当前表现已确认正确，不动。
2. 视频页图标放大到 22px（按钮格 18→22、svg 17→22），向原生按钮格的图标视觉重量对齐；直播页图标保持原样。
3. 写入时机限定在「宿主插入锚点旁」的一次性动作内（mount/relocate 的插入分支，`_fitNativeBox`），不进入每轮 DOM 变更的热路径。

**取舍**:
- 图标取「与 22px 按钮格同高」而非原生字形的精确尺寸：精确对齐需 svg 约 25px（超出按钮格），22px 为折中——字形高度约为原生的 89%、宽度略宽，视觉重量一致。
- 未采用「给宿主设 align-self」的方案：不同播放器行对齐方式不同（视频=贴顶、直播=居中），逐个硬编码会随 B 站改版失配；复刻确定高度与原生按钮同规则更稳。

**后果**: 视频页增益按钮与原生音量键同线、同格高；直播页表现不变（`_fitNativeBox` 带 type 守卫）。
