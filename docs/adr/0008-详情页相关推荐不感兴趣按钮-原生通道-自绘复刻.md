# 详情页相关推荐不感兴趣按钮:原生通道上报 + 自绘像素级复刻

视频详情页右侧栏「相关推荐」卡片缺少主页卡片自带的「不感兴趣（⋮）」菜单，用户需整屏退出才能反馈。决定：在相关推荐卡片右下角注入 ⋮ 按钮，复用 B 站原生 `x/feed/dislike` 上报通道（真正内联推荐系统，非本地假移除），UI 用 Shadow DOM 自绘并**像素级复刻**原生五件套（⋮ 按钮 / 下拉菜单 / 理由二级菜单 / 撤销弹窗 / toast）。

## Status

accepted

## 决策要点

- **上报通道**：走 B 站原生 `POST https://api.bilibili.com/x/feed/dislike`，参数含视频标识（bvid/aid）、理由 id、UP 主 mid、csrf，与主页卡片一致，上报后推荐系统真实降权；不做本地伪装。
- **视频身份来源**：纯 DOM 提取——从卡片 href 解析 bvid、从 UP 主链接解析 mid，零网络请求；不依赖 `related` 接口重查。
- **像素级还原**：直接打开真实 B 站页面采集原生成分的 computed style（字号/色值/圆角/阴影/间距/过渡时长与缓动），逐项搬入 Shadow DOM，不靠截图临摹；动效（展开/淡入/toast 滑入）的 duration + easing 一并照抄。
- **理由清单**：3 条固定理由（`1=这个内容`、`12=此类内容过多`、`13=推荐过`）+ 动态「UP主:用户名」+ 动态「分区/频道名」，与原生接口下发的 id 体系一致（`4=UP主:xxx`、`3=频道:xxx`）。
- **上报后反馈**：完整复刻原生「内容不感兴趣 / 将减少此类内容推荐 / 撤销」浮层；卡片同步淡出列表并保存节点与位置，点撤销后**放回原位**。
- **去重记忆**：本次会话内记录已上报的 bvid，同卡再次出现不再渲染按钮、不重复上报。
- **未登录**：检测不到登录态 csrf 时不渲染按钮（不引导、不打扰）。
- **注入范围**：仅 UGC 视频卡片（含 `/video/` BV 链接）注入；番剧/直播/广告卡不处理，避免理由体系与上报参数错位。

## Considered Options

- **直接搬主页卡片原生节点**：依赖原生组件结构与 JS 内部弹菜单函数，B 站改版即失效；否决，选自绘 + 原生接口（与 SC 浮层同一已验证路线）。
- **本地假移除不上报**：无真实推荐降权效果；用户明确要求内联原生通道，否决。
- **`related` 接口重查取数**：多请求、且同样不含理由清单；否决，纯 DOM 提取足够。

## Consequences

- 依赖 `api.bilibili.com` 域权：需在 manifest `host_permissions` 增加，且上报需以页面身份携带 cookie（同源 fetch 自动携带）。
- 像素还原依赖真实页面采集，B 站改版需重新采集样式基线（记录在文档，改版后对照更新）。
- 会话记忆仅内存态，刷新页面后清空（撤销窗口也随会话结束而消失），与原生行为一致可接受。
