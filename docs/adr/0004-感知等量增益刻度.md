# 0004-感知等量增益刻度（Loudness）

**状态**: accepted

**决策**: 增益显示值从"幅值百分比"（100%–500% 线性）改为**感知响度百分比**（100%–300%），遵循 Stevens 幂律（主观响度 ∝ 幅值^0.6）。内部幅值倍率与感知值换算：幅值 g = (L/100)^(5/3)，L = 100·g^0.6。幅值上限由换算自然得出：感知 300% = 6.24x（+16dB）。

**理由**: 用户实测发现线性幅值刻度下"越往上感受越不明显"——100%→200% 只是 +6dB、主观仅 ×1.52，而系统音量滑块（对数映射）50%→100% 约有 ×2.3 的主观提升，造成体感错位。改为感知等量刻度后，拖动/快捷键/刻度每档的听感变化均匀，对齐 Windows 等系统音量滑块的体验。

**上限 300% 的取舍**: 6.24x 超出"完全无损"的 5x（+14dB）区间约 +2dB：B 站视频/直播实际响度通常留有 12–20dB headroom，正常内容在 300% 下不受影响；仅极端近满刻度素材会触发现有 -1dB/20:1 压缩器限幅（兜底选项 A），表现为该段听感增益递减而非爆音。被否决方案：移除压缩保护换取极限数字响度（必然削波爆音）。

**后果**:
- 区间 100–300 全整数，刻度取 100/150/200/250/300 五档，等感知等距。
- 历史记忆 v1（幅值百分比）在读取时按幂律自动迁移为感知刻度（v2），用户无感。
