# 0004-感知等量增益刻度（Loudness）

**状态**: accepted

**决策**: 增益显示值从"幅值百分比"（100%–500% 线性）改为**感知响度百分比**（100%–263%），遵循 Stevens 幂律（主观响度 ∝ 幅值^0.6）。内部幅值倍率与感知值换算：幅值 g = (L/100)^(5/3)，L = 100·g^0.6。幅值物理上限仍为 5x（对应感知 263%）。

**理由**: 用户实测发现线性幅值刻度下"越往上感受越不明显"——100%→200% 只是 +6dB、主观仅 ×1.52，而系统音量滑块（对数映射）50%→100% 约有 ×2.3 的主观提升，造成体感错位。改为感知等量刻度后，拖动/快捷键/刻度每档的听感变化均匀，对齐 Windows 等系统音量滑块的体验。

**后果**:
- 数值上限 263% 而非 500%：幅值 5x 是物理可无损承载的极限，更高只能靠压缩、听感不再提升；这是诚实限幅（被否决方案：保留显示 500% 但高段无效）。
- 历史记忆 v1（幅值百分比）在读取时按幂律自动迁移为感知刻度（v2），用户无感。
